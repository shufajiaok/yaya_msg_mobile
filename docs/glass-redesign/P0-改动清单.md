## 三、执行与留档规则

1. 按上表 1→8 顺序，**分批 commit / push**，不合并为一次推送（沿用用户的分批 CI 节奏）。
2. 每批完成即在 `CHANGELOG.md` 追加一行：文件、依据章节、验证方式、commit hash。
3. 每批改动后跑 `npm run typecheck`；未装依赖时先 `npm install`（不写回 lockfile 变更则不算改 `package-lock.json`）。
4. 涉及方案文档中的旧行号，一律以工作副本实际内容为准，差异登记进 CHANGELOG。
5. **P0 不做视觉改造**；`AppTabBar` / `ScreenHeader` / `App.tsx` / 各 Screen 属 P1–P3，本轮不碰。
